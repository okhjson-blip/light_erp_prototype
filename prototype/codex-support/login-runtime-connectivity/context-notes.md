# AX ERP 로그인 런타임 연결 컨텍스트 노트

## 2026-07-30

- ERP Vite 개발 서버는 5183번에서 실행 중이나 프록시 대상 8000번 FastAPI는 실행 중이지 않다.
- 로그인 오류는 프런트 요청이 백엔드에 도달하지 못한 결과다.
- 이전 `.venv`는 다른 경로를 가리켜 실행할 수 없었다. `scripts/run-local-api.sh`가 현재 경로의 `.venv-codex`를 준비하고 FastAPI를 8000번에 기동한다.
- Vite 프록시를 통한 실제 브라우저 로그인과 대시보드 전환을 확인했다.
