# AX ERP 통합 로그인 계획

## 목표

기존 역할별 데모 계정을 보존하면서 AX Platform 통합 관리 계정을 idempotent하게 준비하고, ERP 로그인 화면에 비밀번호 보기와 숨기기 토글을 추가한다.

## 범위

1. 실행 환경변수 기반 통합 관리자 upsert CLI를 추가한다.
2. 로그인 화면의 안내와 이메일 기본값을 통합 계정 기준으로 바꾼다.
3. 비밀번호 입력에 보기와 숨기기 토글을 추가한다.

## 검증

1. Python 테스트와 프런트엔드 빌드를 실행한다.
2. 로컬 DB에서 올바른 통합 계정 로그인 성공과 잘못된 비밀번호 거부를 확인한다.
3. 브라우저에서 토글이 비밀번호 입력 type을 전환하는지 확인한다.
