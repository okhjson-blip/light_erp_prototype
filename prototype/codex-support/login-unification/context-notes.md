# AX ERP 통합 로그인 컨텍스트 노트

## 2026-07-30

- 기존 역할별 데모 계정과 테스트 의존 비밀번호는 회귀 보호를 위해 변경하지 않는다.
- 통합 관리 계정은 관리자 역할로 별도 upsert한다.
- 통합 계정의 이메일과 비밀번호는 코드나 문서에 저장하지 않는다. 로컬 계정 upsert는 실행 시 환경변수만 읽는다.
- ERP 프런트엔드 빌드와 Python 회귀 테스트 140건을 통과했다. 로컬 DB에서 통합 계정 로그인은 200, 잘못된 비밀번호는 401을 반환했다.
- 기존 `.venv`는 이전 경로를 가리켜 실행할 수 없었다. 검증 전용 `.venv-codex`를 사용했으며, 프로젝트 소스에는 반영하지 않는다.
